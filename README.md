# Uniface Icon Fonts

This is a library that provides a collection of SVG icon fonts based on the popular Feather font. It is designed to be easy to use and integrate into your projects.

[中文说明](./README-CN.md)

## Installation

You can install the library using npm or yarn:

```shell
npm install @ticatec/uniface-icons
```

## Usage

Once you have installed the library, you can use it in your projects by importing the desired icons.

## Example

```ts
import "@ticatec/uniface-icons/feather-style.css"
```
