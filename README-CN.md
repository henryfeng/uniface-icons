# Uniface 图标字体

这是一个基于流行的 Feather 字体的 SVG 图标字体集合库。它的设计旨在易于使用和集成到你的项目中。

[English Readme](./README.md)

## 安装

你可以使用 npm 或 yarn 安装这个库：

```shell
npm install @ticatec/uniface-icons
```


## 使用

安装库后，你可以通过导入所需的图标来在项目中使用它。

## 示例

```ts
import "@ticatec/uniface-icons/feather-style.css"
```
